## 📖 Descripción

**Ventanal Turístico de Cisneros** es una aplicación web interactiva diseñada para promover el turismo, la identidad cultural y el patrimonio del municipio de **Cisneros (Antioquia, Colombia)**.

El proyecto presenta información organizada de forma visual e intuitiva sobre la historia, sitios turísticos, gastronomía, biodiversidad, cultura y ubicación del municipio mediante una experiencia moderna y completamente responsive.

Además, incorpora una interfaz bilingüe (Español / English), permitiendo que visitantes nacionales e internacionales puedan conocer el municipio de manera accesible.

## 💻 Cómo ejecutar

1. Clona este repositorio.

```bash
git clone https://github.com/tuusuario/ventanal-turistico-cisneros.git
```

2. Entra en la carpeta.

```bash
cd ventanal-turistico-cisneros
```

3. Abre **index.html** en tu navegador favorito.

No requiere instalación ni servidor.
